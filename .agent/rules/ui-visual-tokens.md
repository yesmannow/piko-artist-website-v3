# UI Visual Tokens (Liquid Glass Aesthetic)

- **Color Palette Enforcement**:
  - **Neon Blue (`#00f2ff`)**: To be used for active or boost states.
  - **Rose (`#f43f5e`)**: To be used for cut or alert states.
- **Button Styling**: 
  - All buttons MUST have `border-radius: 9999px` (fully rounded pills/circles).
  - All active buttons MUST have a glow effect of exactly `0 0 15px` using their respective accent color (Neon Blue or Rose).
